1Sous mobile: three directions, each a working prototype

Built from the web app's pages: Week, Plan, Recipes, Find, Recipe, List, Pantry and Add keep their current behaviour and copy. New: a “what do you already have?” review between plan and list, and five ways to add a recipe. Organic's shapes and type (Caprasimo over Figtree, pills, soft circles) carry a phthalo green accent with warm brown as the second voice. Each phone is live: try the brown “Review” notice, + Plan in Find, and the add button. The three differ in navigation, home layout and recipe layout; any combination can be set from Tweaks on SousApp.
